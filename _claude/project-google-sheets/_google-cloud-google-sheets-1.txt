To write to Google Sheets from a backend service or script, you use a **Service Account**. Think of this as creating a "Robot User" for your project.

Here is the exact workflow to configure it, starting from where you are right now.

### The Concept

1. **Identity:** You create a Service Account (the robot).
2. **Credential:** You download a JSON key for this robot.
3. **Access:** You **share** the specific Google Sheet with the robot's email address (just like you would share it with a coworker).

---

### Step 1: Create the "Robot" (Service Account)

You are already on the right page (`IAM & Admin > Service Accounts`).

1. Click **+ CREATE SERVICE ACCOUNT** (top of the screen).
2. **Service account details:**
* **Name:** Give it a clear name like `sheets-writer`.
* **ID:** It will auto-generate (e.g., `sheets-writer@amp-2-....iam.gserviceaccount.com`).
* **Description:** "Writes web transactions to Google Sheets."
* Click **CREATE AND CONTINUE**.


3. **Grant this service account access to project:**
* You can skip this! Google Sheets access is handled at the *sheet level*, not the *project level*.
* Click **CONTINUE**.


4. **Grant users access to this service account:**
* Skip this too.
* Click **DONE**.



### Step 2: Get the "Keys" (The Password)

Now you need the credentials that your code will use to prove it is this robot.

1. In the list of Service Accounts, click the **Email address** of the account you just created.
2. Click the **KEYS** tab (top navigation bar).
3. Click **ADD KEY** > **Create new key**.
4. Select **JSON** (Radio button).
5. Click **CREATE**.
6. **SAVE THIS FILE:** A `.json` file will download to your computer.
* *Security Warning:* This file contains the private key. Do not commit it to public GitHub.
* Move this file to your project folder (e.g., `~/gcp-station/sheets-keys.json`).



### Step 3: Enable the API

Even with a key, your project is "deaf" to Sheets requests until you turn on the hearing aid.

1. In the Google Cloud Console search bar (top), type **"Google Sheets API"**.
2. Select "Google Sheets API" from the Marketplace results.
3. Click **ENABLE**.

### Step 4: Share the Sheet (The Most Important Step)

This is the step most developers forget. Your Service Account is a user, but it has **zero access** to your spreadsheet by default.

1. Open your `.json` key file (or look in the Cloud Console). Copy the **`client_email`** address.
* It looks like: `sheets-writer@amp-2-1704405298450.iam.gserviceaccount.com`


2. Open your target **Google Sheet** in your browser.
3. Click the big **Share** button (top right).
4. Paste the **Service Account email** into the box.
5. Make sure the permission is set to **Editor**.
6. Uncheck "Notify people" (robots don't read email).
7. Click **Share**.

### Step 5: How to Use It (Node.js Code)

Since you are using Node.js v22, I recommend the library `google-spreadsheet`. It is much easier than the raw Google API.

**1. Install Dependencies:**

```bash
npm install google-spreadsheet google-auth-library

```

**2. The Script (`update-sheet.js`):**
You will need the **Sheet ID** from your spreadsheet URL:
`https://docs.google.com/spreadsheets/d/`**`1BxiMVs0XRA5nFMdKvBdBZjgmUUqptnbs74OYrflJDZQ`**`/edit`

```javascript
import { GoogleSpreadsheet } from 'google-spreadsheet';
import { JWT } from 'google-auth-library';
import fs from 'fs';

// 1. Load your JSON Key
const creds = JSON.parse(fs.readFileSync('./sheets-keys.json', 'utf8'));

// 2. Configure Auth
const serviceAccountAuth = new JWT({
  email: creds.client_email,
  key: creds.private_key,
  scopes: ['https://www.googleapis.com/auth/spreadsheets'],
});

// 3. Select the Sheet
const doc = new GoogleSpreadsheet('YOUR_SHEET_ID_GOES_HERE', serviceAccountAuth);

async function writeTransaction() {
  await doc.loadInfo(); // Loads sheet properties
  console.log(`Title: ${doc.title}`);

  const sheet = doc.sheetsByIndex[0]; // Get the first tab

  // 4. Add a Row
  await sheet.addRow({
    Timestamp: new Date().toISOString(),
    TransactionID: "TX-12345",
    Amount: "$99.00",
    Status: "Success"
  });

  console.log("✅ Transaction written to sheet.");
}

writeTransaction();

```
