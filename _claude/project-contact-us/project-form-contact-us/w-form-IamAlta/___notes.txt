The amp-form clear action and <input type=reset> both use the browser's standard reset behavior. The problem here is that amp-bind mutates the value attribute, and the browser behavior for form.reset replaces any existing values in the input fields with the value attribute.

To work around this, you can use on="tap: AMP.setState. I updated your example here: codepen.io/anon/pen/mzzRom
