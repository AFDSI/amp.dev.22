
The https://ampbyexample.com/advanced/autosuggest/search_list is a dynamic endpoint.
If you append a query parameter it will change the results: https://ampbyexample.com/advanced/autosuggest/search_list?q=bois

The bind code changes the src value of the amp-list to send a request with the input box value appended, and the server performs a some computation with the query (like reading from a database for example) and returns the result of the computation.

You have to implement this server logic yourself.
It won't work if it's just passed to a URL that hosts a static JSON file.

If you give each of your list items an id (I think it might need to be non-numeric) and you put that ID in your JSON response, and you render each autosuggest result with an on="tap:{{id}}.scrollTo" it should do the trick.
Here are the docs for scrollTo:
https://github.com/ampproject/amphtml/blob/master/spec/amp-actions-and-events.md#-all-elements


To summarize:

1. Make a server endpoint that filters results.
We have JavaScript server code and Go server code examples.
Make sure these have the appropriate CORS headers.

2. Render the autosuggest items with the ID from the JSON endpoint with a non-numeric ID (I am not sure the numbers you have now for IDs will work)

	{{#results}}
<div
	class="select-option no-outline"
	role="option"
	tabindex="0"
	on="tap:autosuggest-list.hide,{{id}}.scrollTo"
	option="{{title}}"
	>{{title}}</div>
	{{/results}}

3. Put IDs on each of your <li> tags below.
You should have had IDs on these anchor tags or the LIs anyway, not just hrefs.

Now it should work.
